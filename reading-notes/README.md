# Reading Notes

这里用来按日期记录每次阅读《System Design 101》时产生的问题和参考答案。

每个日期直接在 `reading-notes` 下创建一个 Markdown 文件，不再按年份分层：

```text
reading-notes/2026-05-31.md
```

每天可能阅读多篇文档。文件内部建议按下面的结构记录：

```md
# 文档标题或链接

阅读时间：YYYY-MM-DD

## 问题 1：这里写你的问题

**参考答案：** 这里写查证后的答案、文章中的解释，或你整理后的结论。

## 问题 2：这里写另一个问题

**参考答案：** 待补充。
```

如果同一天读了多篇文档，就在同一个日期文件里继续增加新的一级标题。
