# 存储系统概览

我们来整体看看存储系统。

存储系统大致可以分成三类：

* 块存储
* 文件存储
* 对象存储

上图展示了不同存储系统的对比。

## 块存储

块存储最早出现在 20 世纪 60 年代。像 HDD 和 SSD 这种直接物理连接到服务器上的常见存储设备，都属于块存储。

块存储会把原始 block 以卷的形式提供给服务器。这是最灵活、用途最广的存储形式。服务器可以把这些原始 block 格式化后当作文件系统使用，也可以把控制权直接交给应用程序。有些应用，比如数据库或虚拟机引擎，会直接管理这些 block，以榨干它们的性能。

块存储并不局限于物理直连。它也可以通过高速网络，或者通过 Fibre Channel（FC）和 iSCSI 这类标准连接协议接入服务器。从概念上说，网络挂载的块存储仍然提供原始 block。对服务器来说，它的工作方式和物理直连块存储一样。无论是通过网络还是物理连接，块存储都完全归单台服务器所有，不是共享资源。

## 文件存储

文件存储建立在块存储之上。它提供了更高层的抽象，让文件和目录更容易管理。数据以文件形式存放在层级目录结构中。文件存储是最常见的通用存储方案。它可以通过 SMB/CIFS 和 NFS 这类文件级网络协议，让大量服务器访问。访问文件存储的服务器不需要处理块管理、卷格式化这些复杂细节。文件存储的简单性，使它非常适合在组织内部共享大量文件和文件夹。

## 对象存储

对象存储是更新的一类存储形式。它做了一个非常明确的取舍：牺牲性能，换取高持久性、超大规模和低成本。它主要面向相对“冷”的数据，常用于归档和备份。对象存储把所有数据都存成对象，并采用扁平结构，没有层级目录。数据访问通常通过 RESTful API 提供。和其他存储类型相比，它相对更慢。大多数公有云厂商都提供对象存储产品，比如 AWS S3、Google Cloud Storage 和 Azure Blob Storage。
